# college-placement-rag
AI-powered RAG-based college placement assistant that helps students find placement information, company eligibility, interview preparation, and career guidance using college placement documents.
🎓 RAG-Based College Placement Assistant

An AI-powered Retrieval-Augmented Generation (RAG) based college placement assistant designed to help students easily access placement-related information.

📌 About the Project

The RAG-Based College Placement Assistant allows students to ask questions about companies, eligibility criteria, placement processes, interview preparation, resumes, and other placement-related information.

The system retrieves relevant information from college placement documents and provides useful answers to students.

🎯 Objectives

- Provide quick access to college placement information.
- Help students understand company eligibility criteria.
- Provide interview preparation guidance.
- Search placement information using natural language.
- Reduce the time required to manually search placement documents.
- Provide reliable answers based on available placement information.

🧠 RAG Architecture

College Placement Documents
            ↓
       Text Extraction
            ↓
          Chunking
            ↓
        Embeddings
            ↓
       Vector Database
            ↓
      Student Question
            ↓
         Retrieval
            ↓
     Relevant Information
            ↓
           LLM
            ↓
       Generated Answer

💬 Example Questions

Students can ask questions such as:

- What is the eligibility criteria for TCS?
- Which companies recruit MCA students?
- What skills are required for software developer jobs?
- How should I prepare for placement interviews?
- What should I include in my resume?
- What is the typical placement process?
- Can students with backlogs apply?

🚀 How to Run

Frontend Demo

1. Download or clone the repository.
2. Open "index.html".
3. Open it in any web browser.
4. Enter a placement-related question.
5. Click Ask AI Assistant.
